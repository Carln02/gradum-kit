    Type Alias GradumifyOptions

    Description

    Which families of selector functions gradumify should skip. Every family is installed by default; set a flag to leave that family off the GradumSelector prototype. Excluding a family means its functions simply do not exist, so only do it if you know nothing in your app calls them.
