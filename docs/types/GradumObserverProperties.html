    Type Alias GradumObserverProperties<DataType, ComponentType, DataKeyType>

    Description

    Options and lifecycle callbacks used to create a new GradumObserver. Note: self is the second argument of onAdded but the third of onUpdated and onDeleted, which take the existing instance in second place.
