    Class GradumEvent

    GradumEvent

    Description

    The base class for every event the GradumEventManager fires. On top of a native Event it carries the pointer position, the click mode, the input device, the keys held at the time, and the tool the event is attributed to. It also knows how to map screen coordinates into document space, so handlers running under a panned or zoomed canvas can read GradumEvent.scaledPosition instead of doing the maths themselves.
