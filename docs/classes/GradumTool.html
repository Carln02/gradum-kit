    Class GradumTool<ElementType, ViewType, ModelType, EmitterType>

    GradumTool

    Description

    A named mode that changes what interacting with an element does. Its @behavior methods run during the capture phase of the event loop, before any interactor sees the event, so a tool can claim an interaction and stop it reaching the element underneath. Only the active tool for a given click mode receives events.

    activeClasses

    activeClasses: string | string[]

    Description

    CSS class or classes marking that this tool is the active one, added when it is activated and removed when it is not. A tool changes what interacting means, and the page usually has to show it — a different cursor, text that no longer takes a caret — which is a matter for CSS rather than for the tool itself.

    Example

    class EraserTool extends GradumTool {
      public toolName = "eraser";
      public activeClasses = "erasing";  //body.erasing in the stylesheet
    }

    detach

    • detach(): void
      Function

      detach

      Returns void

      Description

      Undoes initialize: the operator stops hearing about anything. Every @listener and @behavior it bound is taken back, everything it subscribed on the emitter while initializing is dropped, and its @effect methods are disposed. Called for you when the operator is removed, before its model, view and emitter are taken away — which is the point, since those are what its callbacks would go on reading.

      The nodes it owns (see own) are removed from the DOM too.

      Initializing it again restores all of it, rebuilding its UI, so an operator may be removed and added back.

      Note: a subscription made outside initialize — later, from a method of its own — is not on the record, and is the operator's own to undo.

      Inherited from GradumOperator.detach
