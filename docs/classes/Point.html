    • from(
          value:
              | number
              | Coordinate
              | [number, number]
              | { clientX: number; clientY: number },
      ): Point
      Function

      from

      Parameters

      • value: number | Coordinate | [number, number] | { clientX: number; clientY: number }

        The value to read.

      Returns Point

      The point, or undefined when the value holds no usable coordinates.

      Static

      Description

      Read a value as a point, checking it first. Accepts everything the constructor does — a number standing for both axes, an x/y pair, a two-number array, an event's clientX/clientY — and hands back undefined for anything that is not one of those, where the constructor would build a point out of NaNs. A value that is already a point is returned as-is, points being immutable.

      Example

      Point.from(50);                //(50, 50)
      Point.from({x: 1, y: 2});      //(1, 2)
      Point.from({width: 10});       //undefined, where new Point({width: 10}) gives (NaN, NaN)
      • Defined in src/gradumComponents/datatypes/point/point.ts:559
