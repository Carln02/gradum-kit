    Class GradumDragEvent

    GradumDragEvent

    Description

    The event fired for gradum-drag, gradum-drag-start, and gradum-drag-end. It tracks every active pointer at once, so a multi-touch drag reports one entry per finger: each map below is keyed by pointer id. Every position is available raw and scaled into document space, along with the per-event deltas.
