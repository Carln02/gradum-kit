    Class GradumEmitter<ModelType, DataKeyType>

    GradumEmitter

    Description

    The base MVC emitter class. Its role is basically an event bus. It allows the different parts of the MVC structure to fire events or listen to some, with various methods.

        The work to run.

      Returns Type

      Whatever the work returned.

      Description

      Run some work and remember that whatever it subscribes belongs to owner, so GradumEmitter.removeFor can take it back later. What the MVC wiring runs a piece's setup inside, so an operator writing this.emitter.add(...) in setupChangedCallbacks is on the record without having to say whose it is.

      Nests safely: the previous owner is restored afterwards, whether the work returns or throws.
