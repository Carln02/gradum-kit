    Class GradumRect

    GradumRect

    Description

    A rectangle that can be rotated, unlike the axis-aligned DOMRect it extends. Its geometry helpers (GradumRect.closestPoint, GradumRect.distanceTo, GradumRect.overlaps) all account for the rotation, and accept a point, a segment, or another rect.

    anchor

    anchor: AnchorPoint

    Description

    The point of the rectangle that x and y give the position of, and that it turns about. Defaults to Anchor.TopLeft, which is what makes an unrotated rectangle read exactly like the DOMRect it extends.

    Every other reading resolves through it — left, top, right and bottom included — so a rectangle describes the same box whichever anchor it carries. Use GradumRect.withAnchor to get an equivalent rectangle stated from a different one.

    topLeft

    • get topLeft(): Point

      Returns Point

      Description

      The corner to lay the rectangle out from: the top-left of the untilted box sitting at GradumRect.center. Rotating that box about its own middle reproduces this rectangle, whatever it is anchored to — which is what makes it the value a translate(...) rotate(...) transform, or a canvas drawImage, wants.

      Note: not the same as the rectangle's actual top-left corner once it is rotated. For that, ask for GradumRect.points[0] or GradumRect.pointAt(Anchor.TopLeft).

      Example

      gradum(el).setStyle("transform", `translate(${rect.topLeft.x}px, ${rect.topLeft.y}px)
          rotate(${rect.angleRad}rad)`);
      • Defined in src/gradumComponents/datatypes/rect/rect.ts:219

    left

    • get left(): number

      Returns number

      Description

      The left edge of the rectangle's box. Resolved through the anchor, like everything else about the rectangle, rather than read off x as DOMRect would — a rectangle anchored anywhere but its top-left has an x that is not its left edge.

      Note: the box here is the untilted one about GradumRect.center, the same one GradumRect.topLeft gives the corner of. A rotated rectangle's four edges are not axis-aligned and cannot be given as four numbers; ask for GradumRect.points for where they actually are.

      Overrides DOMRect.left

    withAnchor

    • withAnchor(anchor: Point | AnchorPoint | Anchor): GradumRect
      Function

      withAnchor

      Parameters

      • anchor: Point | AnchorPoint | Anchor

        The anchor to state it from.

      Returns GradumRect

      The equivalent rectangle.

      Description

      An equivalent rectangle — the same box, in the same place, turned the same way — stated from a different anchor, so its x and y are that anchor's point.

      Which anchor a rectangle carries is not free: it turns about its anchor, so a thing rotated about its own middle has to be stated centre-anchored or its box parts company with it. This is how a caller that wants plain top-left numbers — to hand to something DOM-shaped, or to do arithmetic with — asks for them, rather than redoing the offset by hand or having to know which anchor it was given.

      Example

      const box = node.getBoundingClientRect().withAnchor(Anchor.TopLeft);
      //box.x and box.left now agree, whatever the node reported itself as.
