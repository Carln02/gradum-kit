    Class GradumRect

    GradumRect

    Description

    A rectangle that can be rotated, unlike the axis-aligned DOMRect it extends. Its geometry helpers (GradumRect.closestPoint, GradumRect.distanceTo, GradumRect.overlaps) all account for the rotation, and accept a point, a segment, or another rect.
