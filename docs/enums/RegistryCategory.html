    Enumeration RegistryCategory

    Description

    The bucket a class is filed under in the Gradum Kit registry, and the value getRegisteredByCategories groups by. define infers it by walking the class' inheritance chain; within each family below the categories are listed most to least specific, and the first match wins, so a class extending GradumElement is filed as GradumElement rather than the HTMLElement it also inherits from.
